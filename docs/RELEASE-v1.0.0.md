# 메애기 비서 v1.0.0

내 메애기와 대화하고, 재획을 기록하는 Windows 데스크톱 앱입니다.

## 다운로드와 실행

1. 아래 **Assets**에서 `MaeagiBiseo.exe`를 다운로드합니다.
2. 원하는 폴더에 보관한 뒤 실행합니다. Python을 따로 설치할 필요가 없습니다.
3. 캐릭터를 우클릭해 대화창이나 설정을 열 수 있습니다.

메소 자동 판독을 사용하려면 Windows에 한국어 OCR 언어가 설치되어 있어야 합니다.

## 주요 기능

- 바탕화면 캐릭터 이동, 드래그, 벽 타기와 창 위 착지
- Gemini를 통한 캐릭터 대화와 바탕화면 말풍선
- 캐릭터별 대화 목록, 이름 검색, 프로필 사진 편집
- 이미지·GIF로 캐릭터 추가 및 행동별 이미지 편집
- 넥슨 Open API로 내 메이플스토리 캐릭터 이미지 가져오기
- 메이플스토리 메소·솔 에르다 조각의 로컬 OCR 및 재획 기록
- 라이트·다크 테마와 캐릭터별 페르소나 설정

AI 대화에는 Gemini API 키, 메이플 캐릭터 가져오기에는 NEXON Open API 키를 사용합니다. 기본 캐릭터 표시와 직접 이미지 등록에는 키가 필요하지 않습니다.

## Gemini API 키 발급과 연결

1. [Google AI Studio API Keys](https://aistudio.google.com/apikey)에 Google 계정으로 로그인합니다.
2. 처음 이용한다면 안내에 따라 약관을 확인하고 프로젝트를 준비합니다. 새 사용자는 기본 프로젝트와 키가 자동 생성될 수 있습니다.
3. 사용할 키가 없다면 **Create API key / API 키 만들기**를 눌러 프로젝트를 선택하고 키를 생성합니다. 기존 Cloud 프로젝트가 보이지 않으면 AI Studio의 **Projects**에서 가져옵니다.
4. 생성된 키를 복사합니다.
5. 앱의 **설정 → 대화 연결**에서 Gemini API 키를 붙여 넣습니다.
6. **사용 가능한 모델 불러오기**로 모델을 선택한 뒤 **연결 테스트**를 진행하고 저장합니다.

### 모델과 사용량

앱에서 불러온 모델 목록에서 프로젝트에 사용 가능한 텍스트 모델을 선택하세요. 대화로 재획을 시작하거나 기록을 조회하려면 도구 호출을 지원하는 모델이 필요합니다. 프로젝트의 실제 적용 한도는 [Google AI Studio의 사용 한도](https://aistudio.google.com/rate-limit)에서 확인하세요.

횟수는 채팅 메시지 수가 아닌 API 요청 수입니다. 연결 테스트나 도구 사용에 따른 추가 요청도 사용량에 포함될 수 있습니다. 한도는 프로젝트 단위로 적용되며, 하루 기준은 태평양 시간 자정에 초기화됩니다. 자세한 내용은 [공식 사용 한도 안내](https://ai.google.dev/gemini-api/docs/rate-limits)를 참고하세요.

현재 버전에서는 설정을 저장하면 입력한 Gemini API 키를 현재 Windows 사용자 계정으로 암호화해 저장합니다.

이용 가능 모델, 무료 사용량과 요금은 계정·프로젝트별로 다릅니다. [API 키 공식 안내](https://ai.google.dev/gemini-api/docs/api-key)와 [요금 안내](https://ai.google.dev/gemini-api/docs/pricing)를 확인하세요.

## 넥슨 API 키 발급과 캐릭터 가져오기

1. [NEXON Open API](https://openapi.nexon.com/ko/)에 넥슨 계정으로 로그인합니다.
2. **내 애플리케이션 → 애플리케이션 등록**을 엽니다.
3. 게임에서 **메이플스토리**를 선택합니다. 애플리케이션 타입별 안내를 확인하고 서비스명 등 필수 정보를 입력한 뒤 약관을 확인하고 등록합니다.
4. **내 애플리케이션 → 등록한 애플리케이션 상세**에서 발급된 API Key를 복사합니다.
5. 앱 설정에서 **메애기 만들기 · 편집**을 열고, 메이플 캐릭터 이름과 넥슨 API 키를 입력합니다.
6. **메이플에서 불러오기**를 누른 뒤 이미지와 크기를 확인하고 저장합니다.

넥슨 API 키는 Gemini 키와 별개입니다. 캐릭터를 불러올 때 직접 입력한 넥슨 키는 Windows 사용자 계정으로 암호화해 보관합니다. 캐릭터 조회 실패 시 이름, 키의 메이플스토리 접근 권한과 API 요청 한도를 확인하세요.

발급 화면과 애플리케이션 타입에 관한 자세한 내용은 [넥슨 공식 준비 안내](https://openapi.nexon.com/ko/guide/prepare-in-advance/)를 참고하세요.

## 데이터와 참고사항

- 배포 EXE에 개인 API 키는 포함하지 않습니다. 각자 발급받은 키를 입력해 사용하세요.
- 게임 화면의 OCR은 PC에서 처리합니다. 화면 이미지를 AI 서버에 보내지 않습니다.
- AI 대화 메시지와 대화에 필요한 도구 결과는 Gemini API로 전송됩니다.
- 사용자 캐릭터와 기록은 `%LOCALAPPDATA%\DesktopShimeji\` 아래에 저장합니다.
- 화면 인식은 해상도·배율·게임 UI 배치에 따라 다를 수 있습니다. 인식이 맞지 않으면 설정의 **게임 화면 인식**에서 영역을 지정하세요.
- 메이플스토리 이미지의 권리는 넥슨 및 해당 권리자에게 있으며, 이 앱은 넥슨의 공식 제품이 아닙니다.
